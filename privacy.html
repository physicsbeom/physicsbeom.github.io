공가(Gongga) 개인정보처리방침

'공가'(이하 '앱')는 부부 및 가족이 함께 사용하는 스마트 가계부 애플리케이션으로, 이용자의 개인정보를 매우 중요하게 여기며 관련 법령을 준수합니다.

1. 수집하는 개인정보 항목 및 수집 방법

본 앱은 별도의 독립된 외부 개발자 서버를 일절 운영하지 않습니다. 따라서 이용자의 개인정보는 앱 내부 저장소 및 이용자 본인이 직접 연동한 개인 Google 드라이브(스프레드시트)에만 저장됩니다.

  • 필수적 정보: Google 로그인 계정 이메일 및 프로필 정보 (Google Sign-In 연동 시)
  • 선택적 권한 정보 (기기 내 처리):
    • SMS 문자 및 알림 접근: 카드 승인 문자 및 결제 푸시 알림 내용 (기기 내에서 가계부 입력 데이터로 자동 변환되며 외부 서버로 전송되지 않음)

2. 개인정보의 수집 및 이용 목적

  • 부부 및 가족 간 Google 스프레드시트를 통한 실시간 가계부 데이터 동기화
  • 카드 승인 문자 및 푸시 알림을 이용한 가계부 자동 입력 편의 제공
  • 비상 백업 시트 생성 및 데이터 복원 기능 지원

3. 개인정보의 보유 및 파기

이용자가 앱 내 설정에서 계정을 로그아웃하거나 앱을 삭제하는 경우, 기기 내에 저장된 모든 데이터는 즉시 파기됩니다. Google 드라이브에 생성된 스프레드시트 데이터는 이용자가 직접 드라이브에서 삭제할 때까지 보관됩니다.

4. 구글 사용자 데이터 공유 및 이전 (Sharing and Transfer of Google User Data)

[한국어] '공가(MyBudget)' 앱은 수집하거나 접근한 Google 사용자 데이터(Google 스프레드시트 데이터 및 Google 드라이브 파일 메타데이터)를 어떠한 제3자에게도 판매, 거래, 임대하거나 외부로 전송·공개하지 않습니다. 모든 데이터는 오직 사용자 본인의 기기와 사용자가 직접 권한을 부여한 본인의 Google 드라이브(스프레드시트) 계정 내에서만 처리됩니다. (단, 사용자가 직접 가족/배우자와 공유하기로 선택한 특정 스프레드시트 파일은 사용자가 지정한 Google 드라이브 공유 권한 설정에 한해서만 공유됩니다.)

[English] MyBudget (Gongga) does NOT sell, trade, rent, share, transfer, or disclose any Google user data (including Google Sheets data and Google Drive file metadata) to any third parties or external servers. All Google user data is processed strictly locally on the user's device and stored directly within the user's own Google Drive / Google Sheets account. Data is only accessible to other users if the user explicitly shares their Google Spreadsheet via Google Drive's native sharing settings (e.g., sharing a household ledger with a spouse). Our use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 민감 데이터 보호 및 보안 메커니즘 (Data Protection and Security Mechanisms)

[한국어] 당사는 사용자의 민감한 재무 및 Google 데이터를 보호하기 위해 다음과 같은 보안 메커니즘을 적용합니다:

  • 전송 구간 암호화: 앱과 Google API(Google Sheets API, Google Drive API) 간의 모든 데이터 통신은 산업 표준인 HTTPS/TLS(SSL) 암호화 프로토콜을 통해서만 이루어집니다.
  • 외부 서버 무저장(Serverless 아키텍처): 개발자가 운영하는 별도의 외부 데이터베이스나 서버가 존재하지 않으며, 모든 데이터는 안드로이드 OS의 샌드박스 내부 전용 저장소(SharedPreferences)와 사용자 본인의 Google 계정에만 저장됩니다.
  • 안전한 인증 토큰 관리: OAuth 2.0 액세스 토큰은 기기 메모리 및 보안 영역에서만 일시적으로 사용되며 외부로 유출되지 않습니다.

[English] We implement strict security and data protection mechanisms to safeguard sensitive Google user data:

  • Encryption in Transit: All data transmitted between the application and Google APIs (Google Sheets API and Google Drive API) is encrypted using industry-standard HTTPS / TLS 1.2+ protocols.
  • Zero External Server Storage: We do not operate any external backend servers or databases. All ledger data and settings are stored exclusively in the Android OS private sandboxed storage (Context.MODE_PRIVATE) on the user's device and in the user's own Google Drive/Sheets account.
  • Access Control & Token Security: OAuth 2.0 access tokens are managed via official Google Play Services Auth SDKs in memory and are never logged or transmitted to third parties.
